# Student Check-in: Light Rays

A formative pre-learning check-in for Grade 8 STEAM, Lesson 6: Light Rays.

Students answer a short set of open prompts before the lesson videos. There is no score, nothing is submitted anywhere, and nothing is stored or sent over the network. At the end, a summary screen compiles their answers with Print and Copy buttons, so students can keep or paste their responses.

Single-file HTML app (all CSS and JavaScript inline, no external resources, works offline). Open index.html in a browser, or view it on GitHub Pages once Pages is enabled for this repository.
